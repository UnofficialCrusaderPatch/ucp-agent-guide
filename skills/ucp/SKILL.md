3. Read [docs/mistakes.md](https://github.com/UnofficialCrusaderPatch/ucp-agent-guide/blob/main/docs/mistakes.md) to avoid recurring extension defects.
4. Check the target framework and dependency revisions before choosing a configuration shape, API, or native binding; items marked `(3.0.8)` require the unreleased framework draft.
