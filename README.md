# ucp-agent-guide
Rules and an API map for writing UCP3 extensions, for agents and people (see [UCP-Wiki](https://github.com/UnofficialCrusaderPatch/UCP-Wiki) for human tutorials).
- [AGENTS.md](AGENTS.md) — extension types, manifests, Lua/DLL APIs, Store packaging, and rules.
- [docs/where-to-find.md](docs/where-to-find.md) — API map of framework and owning-module helpers with source pins.
- [docs/mistakes.md](docs/mistakes.md) — recurring extension mistakes and what to do instead.
- [skills/ucp/SKILL.md](skills/ucp/SKILL.md) — agent skill pointing to these docs.

Copy or link `AGENTS.md` into an extension repo, or install `skills/ucp` for Claude Code or Codex. Items marked `(3.0.8)` describe the unreleased framework 3.0.8 draft.
