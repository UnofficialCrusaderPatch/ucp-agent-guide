# Where to find framework and module APIs

Use the owning API below instead of rebuilding it. Framework APIs are available to modules through the module environment. Plugins see only declared `public` names on a dependency.
Framework Lua pins are relative to `content/ucp/code/` at draft PR #156 `a67270a` (released `v3.0.7` is `77c6acc`). Items marked `(3.0.8)` belong to the unreleased draft.

| Require one unique AOB match | Framework `core.AOBScanUnique(pattern)` (3.0.8): scans executable sections of the main executable on each call; returns address, or `nil` and `"not found"`, `"found more than once"`, or `"not searched completely"` (bad pattern errors); store the result locally. | `core.lua:232–238,337–349@a67270a`; RPS PR #16 `AOB.cpp:121–159`, `CodeFunctions.cpp:1119–1144@203a694` |
